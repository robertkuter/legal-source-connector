# Source manifest examples

These are small metadata examples showing how the connector describes an official
source snapshot and its index health. They do not contain the complete Acts.

`abl-source-manifest.v0.1.json` is an example derived from the cached Riksdagen
snapshot for Aktiebolagslag (2005:551). Its hashes and consolidation marker identify
that snapshot; they are not a claim that the source is live or unchanged today.
